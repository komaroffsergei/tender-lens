# Static UI prototype

Открыть `index.html` в браузере или запустить:

```bash
python -m http.server 8080
```

Прототип использует только фиктивные данные и показывает визуальное намерение. Codex должен перенести структуру и стили в `src/tender_lens/web/`, заменить демонстрационное поведение реальными вызовами `/api/v1/search` и `/api/v1/ask`, сохранить безопасный вывод через DOM API и не добавлять npm.

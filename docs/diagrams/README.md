# Диаграммы

- `architecture.mmd` / `architecture.png` — компоненты и связи.
- `crawl-sequence.mmd` — последовательность crawl → index.
- `ask-sequence.mmd` — API key → limiter → retrieval → answer.
- `data-model.mmd` / `data-model.png` — пять таблиц и связи.
- `pipeline-sequence.png` — упрощённая вертикальная схема для README/собеседования.

Mermaid является редактируемым источником смысловой схемы. Graphviz `.dot` используется для поставляемых PNG без зависимости от внешнего renderer. При изменении архитектуры обновляются оба представления либо документируется, какое из них является актуальным.

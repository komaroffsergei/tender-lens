Демонстрационный режим: используются моки

Embeddings заменены детерминированным хешированием токенов, LLM — шаблонным ответом из найденных фрагментов. NATS, извлечение текста, PostgreSQL и cosine search работают реально. Показатель cosine не является оценкой качества модели.

Что происходит

  1. Запрос превращается в embedding.
  2. PostgreSQL находит ближайшие чанки.
  3. В режиме ответа мок использует только найденные фрагменты.
